<h2>Overview</h2>
<p>
  The <strong>Outbound Clipboard Manager</strong> streamlines daily communication, standardizes workflow messaging, and accelerates repetitive tasks for the University of Utah Health Outbound Team.
</p>

<h2>Key Features</h2>
<ul>
  <li>
    <strong>Custom Copy Buttons:</strong> Create and organize user-defined buttons for rapid, one-click copy-pasting of frequently used text snippets and templates.
  </li>
  <li>
    <strong>Dynamic Tagging System:</strong> Apply unique tags across multiple buttons to update shared variables or specific information simultaneously without editing buttons individually.
  </li>
  <li>
    <strong>Wait List Outreach Generator:</strong> Generate standardized outreach communications on the fly by entering a few key pieces of information.
  </li>

<li>
    <strong>Static Copy Buttons:</strong> A pre-configured library of standard information and outreach communications to ensure consistent messaging across the team.
  </li>
  </ul>

<h2>Tech Stack</h2>
<ul>
  <li><strong>Frontend:</strong> HTML5, CSS3, Vanilla JavaScript</li>
</ul>
